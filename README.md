# Scam Stop

This repository has two top-level folders:

- [`backend/`](backend/) contains the FastAPI service, developer console, tests, samples, and documentation. See its [README](backend/README.md) for setup and run commands.
- [`frontend/`](frontend/) is reserved for the separately built product front end. It can use the [API contract](backend/API.md).

Run backend commands from `backend/`. Its `.env` file, if used, also belongs there.
